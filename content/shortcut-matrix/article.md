# タイピングを速くする前に、入力中の「停止」を減らす

仕事が速い人は、必ずしも1秒あたりの打鍵数だけが多いわけではありません。候補を確定する、入力モードを変える、句読点を切り替える。そのたびに手と考えが止まらないよう、操作の流れを整えています。

KeyroIMEは、よく使う設定をトレイメニューとキーボード操作の両方から扱えるようにしています。この記事では、覚える価値のある操作だけを選び、自分用の「ショートカット表」を作ります。

## 現在使える主な操作

| 操作 | 機能 | 条件・補足 |
| --- | --- | --- |
| 数字 `1`〜`5` | 表示中の候補を直接確定 | 未確定の読みと候補があるとき |
| `Space` / `↓` / `Tab` | 候補を下へ移動 | 候補表示中 |
| `↑` / `Shift + Tab` | 候補を上へ移動 | 候補表示中 |
| `、` / `。` | 前／次の候補ページ | 候補表示中。欧文設定では `,` / `.` |
| `Alt + ~` | ひらがな／英語 | ANSI配列状態 |
| `Alt + ;` | JIS／ANSI | セミコロン位置のキー |
| `Shift + CapsLock` | 半角／全角 | ANSI配列状態 |
| `CapsLock` | 英語大文字／小文字ロック | 英語入力時 |
| `Shift` 単押し | 和文／欧文の句読点 | 他のキーと組み合わせない |

JISキーボードでは、半角／全角／漢字キーなど固有のキーも利用できます。アプリが同じショートカットを使っている場合や、リモート接続中は動作が変わることがあります。

## 全部を覚えない

ショートカットは、多いほど効率的になるわけではありません。次の順番で一つずつ加えます。

1. 候補を頻繁に選ぶ人は、数字キー1〜5から始める。
2. JISとUSを使い分ける人は、`Alt + ;` を加える。
3. 英数字の全角誤入力が多い人は、`Shift + CapsLock` を加える。
4. 日本語と英語を往復する人は、`Alt + ~` を試す。
5. 和文と欧文の句読点を使い分ける人は、Shift単押しを試す。

一週間で全部を覚えようとせず、同じ誤操作が何度も起きる項目だけを選びます。

## 自分用の計測表を作る

普段よく書く200〜300文字のメールや説明文を一つ用意します。ショートカットを追加する前後で、次を記録します。

| 項目 | 追加前 | 追加後 |
| --- | ---: | ---: |
| 完成までの時間 |  |  |
| 候補確定のEnter回数 |  |  |
| 入力モードの切り替え回数 |  |  |
| 全角・半角の修正回数 |  |  |
| 誤操作から戻した回数 |  |  |

1回だけでは慣れの影響が大きいため、同じ条件で数回試します。短縮時間だけでなく、修正や迷いが減ったかも見てください。

## 反応しないとき

1. Windowsの入力方式でKeyroIMEが選ばれているか確認します。
2. JIS／ANSIなど、ショートカットの条件を確認します。
3. メモ帳で同じ操作を試します。
4. メモ帳で動く場合は、対象アプリのショートカット設定を確認します。
5. トレイメニューから同じ設定を変更できるか確認します。

ショートカットを増やす目的は、操作を複雑にすることではありません。繰り返している停止を一つずつ減らし、文章の内容へ使える注意を増やすことです。
