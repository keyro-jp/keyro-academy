# @やURLを全角にしない。半角の数字・記号を迷わず入力する

メールアドレスの `@`、URLの `https://`、ファイル名の `_`、コードの `=`。仕事で毎日使う文字ですが、日本語入力中に全角の `＠` や `＝` になると、削除して打ち直すことになります。

大切なのは、記号のキー位置だけでなく、**文字幅が半角か全角か**を分けて見ることです。KeyroIMEは既定の半角入力と、文字幅を明示的に切り替える操作を用意しています。

## 全角では困る場面

見た目が似ていても、半角と全角は別の文字です。

| 用途 | 期待する例 | 間違いやすい例 |
| --- | --- | --- |
| メール | `user@example.com` | `user＠example.com` |
| URL | `https://example.com` | `ｈｔｔｐｓ：／／example.com` |
| ファイル名 | `report_2026.pdf` | `report＿2026.pdf` |
| コード | `if (x == 10)` | `if（x ＝＝ 10）` |
| 数値 | `+12.5%` | `＋１２．５％` |

フォームの検証、検索、プログラムでは、全角文字がエラーや検索漏れの原因になることがあります。

## KeyroIMEで文字幅を確認する

1. 通知領域のKeyroIMEアイコンを開きます。
2. 「文字幅設定」で「半角」または「全角」を確認します。
3. ANSI配列の状態では、`Shift + CapsLock` でも半角／全角を切り替えられます。
4. メモ帳で `user@example.com` と `2026/09/21` を入力します。

OpenCore v1.0.6.16の既定値は半角です。普段のメール、URL、コードでは半角を基本にし、全角英数字が必要な文書だけ切り替えると状態を管理しやすくなります。

## 記号の位置が違う場合

`Shift + 2` を押して `@` ではなく `"` が出る場合、文字幅ではなくキーボード配列の違いが原因かもしれません。

- US英語配列：`Shift + 2` で `@`
- 日本語JIS配列：Pの右側のキーで `@`

KeyroIMEのJIS／ANSI設定は、トレイメニューまたは `Alt + ;` で切り替えられます。文字幅と配列は別設定なので、順番に切り分けてください。詳しい比較は[JIS・US配列の違いと切り替え方](https://github.com/keyro-jp/keyro-academy/blob/main/content/jis-ansi-tokyo-ja/article.md)で紹介しています。

## 1分の入力テスト

次の文字列をメモ帳へ入力します。

```text
sales@example.com
https://example.com/report_2026_v2.pdf
total = (1250 + 250) * 1.10
```

確認項目は3つです。

1. すべて半角か
2. `@`、`:`、`_`、`=`、括弧がキーの印字どおりか
3. メモ帳と普段使うアプリで結果が同じか

メモ帳だけ正しい場合は、アプリ固有のショートカットやリモート接続先の設定も確認します。会社の管理PCでは、設定変更やソフト導入の社内ルールに従ってください。

## 「打つ速さ」より「打ち直さない」

記号1文字の入力時間は短くても、全角に気づき、削除し、設定を戻し、再入力する流れは文章のリズムを止めます。KeyroIMEが目指すのは、最大速度の数字を示すことではなく、こうした修正操作を減らすことです。
