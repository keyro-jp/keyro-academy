# 絵文字と顔文字、どう出す？ vemoji と vkaomoji の使い方

メッセージに絵文字をひとつ入れたい。でも、一覧から探すのは少し面倒。そんなときは、KeyroIME Proの日本語入力で `vemoji` と打ってみてください。絵文字の候補一覧が開きます。

顔文字なら `vkaomoji`。短く `vkao` でも呼び出せます。

| 入力 | 探せるもの |
| --- | --- |
| `vemoji` | 絵文字（`vmoji` も可） |
| `vkaomoji` | 顔文字（`vkao` も可） |

## まず試すなら

1. WindowsでKeyroIME Proを選び、日本語入力にします。
2. メモ帳に `vemoji` と入力します。
3. 候補から使いたい絵文字を選んで確定します。顔文字も同じように `vkaomoji` で試せます。

候補の右側にある `Emoji` や `顏` は種類を示す表示です。確定した文章には入りません。候補を送るときは `↓` や `Tab`、戻すときは `↑` や `Shift+Tab` を使えます。

記号を探したい日は `vkigou`（別名 `vcode`）も使えます。

絵文字の色や形は、入力先のアプリやフォントによって変わることがあります。送信前に、実際の画面で見え方を確認してください。ここで入力できるのは文字の絵文字・顔文字で、GIFや動画ではありません。
