# 候補を選んだのに、なぜEnter？数字キー1〜5で直接確定する

日本語入力では、読みを打ち、候補を選び、最後にEnterで確定する操作がよく使われます。しかし候補を選んだ時点で、入力したい語はすでに決まっています。

KeyroIMEは、候補ウィンドウの番号と数字キーを対応させ、**1〜5を押した時点で候補を確定**します。この記事では、通常の候補移動との違い、試し方、使うときの注意点を整理します。

## 操作の違い

たとえば「こうかん」と入力し、候補に次の5件が表示されたとします。

```text
1 交換
2 交歓
3 交換する
4 好感
5 高官
```

KeyroIMEでは、目的の候補に付いた `1`〜`5` を押すと、その候補が本文へ入り、変換が終了します。番号を押したあとにEnterを追加する必要はありません。

候補は1ページ5件です。別のページを見る場合は、次の操作を使えます。

| 操作 | 動き |
| --- | --- |
| `1`〜`5` | 表示中の候補を直接確定 |
| `Space` / `↓` / `Tab` | 候補を下へ移動 |
| `↑` / `Shift + Tab` | 候補を上へ移動 |
| `。` / `.` | 次の候補ページ |
| `、` / `,` | 前の候補ページ |
| `Enter` | 選択中の候補、または入力中の文字を確定 |

句読点キーによるページ送りは、KeyroIMEの候補ウィンドウが開いている間の操作です。通常の文章入力では、設定した句読点が入力されます。

## 30秒で試す

1. メモ帳を開き、Windowsの入力方式からKeyroIMEを選びます。
2. ひらがなモードで `こうかん` と入力します。
3. 候補ウィンドウに表示された目的の語の番号を確認します。
4. 対応する数字キーを1回押します。
5. 文字が本文へ入り、候補ウィンドウが閉じることを確認します。

続けて別の文章を入力できれば、数字キーによる直接確定が動作しています。

## 数字を入力したいときの注意

未確定の読みと候補がある状態では、Shiftを押していない `1`〜`5` は候補選択として扱われます。数字そのものを入力したい場合は、先に読みを確定するか、英語モードへ切り替えてから入力してください。候補が出ていない状態では、数字は通常の文字として入力できます。

この違いを知っておくと、「文章中の数字を入れようとして候補が確定した」という混乱を避けられます。

## 効果は「削減したキー数」で測る

直接確定は、候補を選んだあとにEnterを押していた操作を1回減らす設計です。ただし、仕事全体の短縮時間は文章の量、候補の位置、従来の入力方法で変わります。

比較するときは、同じ文章を2回入力し、次を記録すると判断しやすくなります。

- 候補を確定した回数
- Enterを押した回数
- 候補を探すためにページを移動した回数
- 誤って確定し、修正した回数

「速く感じる」だけでなく、自分の作業で本当に操作が減ったかを確かめられます。
