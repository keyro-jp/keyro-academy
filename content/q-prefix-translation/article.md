# 「q＋語」で日英・英日の訳語を探す

メールを書いていて「この単語、英語で何だっけ？」と思ったら、入力中のまま `q` を付けてみてください。KeyroIMEが翻訳辞書の候補を優先して表示します。

```text
qスケジュール  → 英語の候補を探す
qschedule    → 日本語の候補を探す
```

## 使い方はかんたん

1. KeyroIMEで日本語入力にします。
2. `q` に続けて、調べたい日本語や英単語を入力します。
3. 候補を見て、使いたい語を選んで確定します。

候補の「訳」タグと先頭の `q` は、確定した文章には入りません。候補が複数あるときは、数字キー `1`〜`5` で表示中の候補を直接選べます。

これは**単語や短い語句の辞書検索**です。文章全体を翻訳したり、文脈に合う訳を自動で判断したりする機能ではありません。候補が見つからないときは語を短くして試し、正確な訳が必要なら辞書や正式な用語集で確認してください。

**キーワード：** KeyroIME、Windows、IME、日本語入力、日英翻訳、英日翻訳、`q＋語`
