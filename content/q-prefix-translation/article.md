# 英語を調べるために画面を離れない。「q＋語」の翻訳候補

文章を書いている途中で、「スケジュールは英語でどう書く？」「scheduleは日本語で何だっけ？」と手が止まることがあります。ブラウザーを開き、検索し、元の画面へ戻ると、一語の確認以上に時間と集中を使います。

KeyroIMEには、入力の先頭に `q` を付けて、**日英・英日の翻訳候補を優先する辞書検索**があります。文章を入力している場所から、対応語の候補へアクセスする機能です。

## 2方向で使える

```text
qスケジュール
qschedule
```

`qスケジュール` では英語側、`qschedule` では日本語側の候補を探します。候補には「訳」の分類表示が付きますが、確定した本文にはタグや先頭の `q` は入りません。

操作は通常の候補と同じです。

| 操作 | 動き |
| --- | --- |
| 数字 `1`〜`5` | 表示中の候補を直接確定 |
| `Space` / `↓` / `Tab` | 次の候補へ移動 |
| `↑` / `Shift + Tab` | 前の候補へ移動 |
| `。` / `.` | 次の候補ページ |
| `、` / `,` | 前の候補ページ |

`q` を付けた検索では、各ページで翻訳辞書の候補を優先して表示します。完全一致だけでなく前方一致の候補も扱います。

## まずメモ帳で試す

1. Windowsの入力方式でKeyroIMEを選びます。
2. `qスケジュール` と入力し、候補に英語の対応語が出るか確認します。
3. 数字キーで候補を確定します。
4. 次に `qschedule` と入力し、日本語側の候補を確認します。
5. 普段使うメール、エディターでも同じ操作を試します。

候補が見つからない場合は、語尾を短くして前方一致を試すか、通常の辞書・検索サービスで確認してください。

## 翻訳サイトとの役割の違い

この機能は、単語や短い対応語を入力中に探すための辞書候補です。長文翻訳、文脈に応じた語義選択、専門分野の正確な訳文を保証するものではありません。

特に契約、医療、法務、安全に関わる文章では、候補をそのまま採用せず、専門辞書や組織の用語集、必要に応じて専門家の確認を使ってください。

| 用途 | 向いている確認方法 |
| --- | --- |
| スペルを思い出す | `q＋日本語` の候補 |
| 英単語の日本語候補を見る | `q＋英語` の候補 |
| 一文全体を訳す | 翻訳サービスや専門ツール |
| 社内の正式用語を使う | 組織の用語集・単語登録 |
| 高い正確性が必要 | 原典・専門家による確認 |

## 現在の辞書機能とAI Proを分ける

`q` の翻訳候補は、現在のローカル辞書機能です。AI Proで計画している校正、書き換え、長文支援とは別です。この記事はAIによる翻訳や一般提供を示すものではありません。

入力、候補検索、確定までを同じ場所で行えるため、ブラウザーへ移動する回数を減らせる場面があります。実際の効果は、普段調べる語と辞書に含まれる候補によって変わります。

`q` による日英・英日候補の優先は、OpenCore v1.0.6.16およびPro v1.0.6.17の資料・実装で確認しています。最新版は[公式リリース](https://github.com/keyro-jp/KeyroIME-Releases/releases)、版の違いは[OpenCore・Pro・AI Proの違い](https://github.com/keyro-jp/keyro-academy/blob/main/content/keyro-editions/article.md)をご確認ください。
