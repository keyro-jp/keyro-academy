# Claudeと数学者が挑んだ167年の難問｜リーマン予想とAIの転換点

数学者が167年も取り組んできた宿題に、AIが途中参加しました。2026年11月20日、数学者レヴェント・アルポゲ（Levent Alpöge）氏は、Claudeと協力してリーマン予想の証明を見つけたと発表。翌21日、LeanとMathlibのコミュニティは、複数の検証器で証明を確認したと発表しました。11月23日時点で、賞を管理するクレイ数学研究所の掲載は「Active」です。 [本人の発表](https://alpo.ge/remark.pdf)・[検証チームの共同声明](https://leanprover-community.github.io/blog/posts/riemann-hypothesis/)・[研究所の問題ページ](https://www.claymath.org/millennium/riemann-hypothesis/)

## 素数の数え方に、なぜ「1/2」が出てくる？

2、3、5、7、11。素数は、1と自分自身でしか割り切れない、2以上の整数です。並びは気まぐれに見えますが、大きな範囲で見れば「この辺りまでに何個あるか」は見積もれます。では、その見積もりはどれくらい外れるのでしょうか。

リーマンは1859年、そのズレを「ゼータ関数」という数式で調べました。数式の値がゼロになる点のうち「非自明な零点」と呼ばれるものが、すべて複素平面の横座標が1/2の縦線に並ぶ、というのがリーマン予想です。点は無限にあり、いくら先まで確かめても、それだけで「すべて」とは言えません。証明によって素数の分布のズレを鋭く抑えられ、予想を前提にしていた数論の結果にも確かな根拠が加わります。 [クレイ数学研究所の解説](https://www.claymath.org/millennium/riemann-hypothesis/)

## 数学者が道を選び、Claudeが手を進め、Leanが確かめた

1. **手掛かりを探す。** アルポゲ氏は、構造が似ていて扱いやすい問題で使えた二つの発想を、本題でも組み合わせようとしました。
2. **証明の手を組み立てる。** 本人の説明によると、Claudeは「テータ・リフト」という変換を何段もつなぎ、その段数を対象の規模の平方根ほどにする案を出しました。証明の大筋は、素数に関係する和のズレを抑える不等式を示し、零点が1/2の線から外れないことを導く、というものです。
3. **証明を機械で検証する。** 公開されたLeanライブラリは約1,700万行。検証チームは、そのコードが証明した命題が数学ライブラリMathlibの定義と一致することを確かめ、出力された証明をLean本体と独立した検証器で照合しました。ここまで長いと、紙に印刷する前にプリンターが休暇を申請しそうです。

[本人の発表](https://alpo.ge/remark.pdf)・[数学者による証明の読み解き](https://www.math.uwaterloo.ca/~mrubinst/alpoge_claude_grh/)・[検証チームの共同声明](https://leanprover-community.github.io/blog/posts/riemann-hypothesis/)

### Leanの検証を1分で試す

[ブラウザー版Lean](https://live.lean-lang.org/)に次の2行を貼り付けます。「PとQが両方成り立つ」という前提から、順番を変えて「QとPが両方成り立つ」と示す例です。1行目が証明したいこと、2行目がその根拠です。

```lean
example (P Q : Prop) (h : P ∧ Q) : Q ∧ P :=
  And.intro h.right h.left
```

2行目の `h.right h.left` を `h.left h.right` に入れ替えると、Leanは型の不一致を示します。証明の一歩ごとに、求められた主張と根拠が合っているかを確認する仕組みです。 [Lean公式チュートリアル](https://lean-lang.org/theorem_proving_in_lean4/Tactics/)

## AIは「発見を手伝う」という境目を越えた

この出来事を、研究の進め方における一つの「特異点」だと考えます。人が良い問いを選び、AIが専門家も驚く手を提案し、その結果を第三者が検証する。こうした協力が広がれば、数学に限らず、人間だけで試せる範囲を超えて新しい発見を目指せます。

日常でも、例えば打ち合わせメモをAIに「決まったこと、担当、期限に整理して。不明な点は『未確認』と書いて」と頼めます。出てきた担当と期限を元のメモで照合し、確認時間まで含めて手作業と比べてみましょう。浮いた時間は「そもそも次の会議は必要？」と考えるために使えます。

AIで試せる案が増えるほど、何を問うか、どう確かめるかに人の工夫が生きます。私たちが次に届く高さは、その工夫しだいです。
