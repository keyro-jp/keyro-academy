# 海外のPCで「半角／全角キーがない！」US配列の予習と日本語入力

留学先のPCルームで、レポートを書こうとしたとき。海外の職場で、メールアドレスを入力しようとしたとき。「半角／全角キーがない」「Pの右に@が見つからない」と、手が止まることがあります。

渡航前に覚えておきたいのは、海外のキーボードを一括りにしないこと。そして、**記号の場所と日本語入力の切り替えを、別々に確認すること**です。

この記事ではUS英語配列を使う場面に絞り、短い練習とKeyroIMEでの設定確認を紹介します。KeyroIME開発元からの機能紹介を含みます。

## 渡航先のキーボードは、まず確認する

海外にはUS配列だけでなく、英国などで使われる配列やISO形状のキーボードもあります。「海外なら100% US配列」とは限りません。大学や職場が使うPC、OS、キーボードの種類を、可能なら事前に確認しておきましょう。

ANSIはキーの物理的な並び方、USは文字の割り当てを指します。日本語JISキーボードとは、記号の位置だけでなくEnterやスペースの形、変換・無変換キーの有無も異なります。ソフトの設定で変更できるのは主に文字の扱いで、キーの形そのものは変わりません。

## 出発前に覚える、5つの記号

一般的なUS英語配列と日本語JIS配列を、対応する設定で使う場合の比較です。半角英数字を入力する状態で試してください。

| 入力したい文字 | US英語配列 | いつもの日本語JIS配列 |
| --- | --- | --- |
| `@` | `Shift + 2` | Pの右の `@` キー |
| `"` | `Shift + '` | `Shift + 2` |
| `(` / `)` | `Shift + 9` / `Shift + 0` | `Shift + 8` / `Shift + 9` |
| `=` | `=` キー | `Shift + -` |
| `+` | `Shift + =` | `Shift + ;` |

メールの宛先、引用符、括弧、計算式。この5つを押さえるだけでも、どの記号で手が止まるのか把握できます。実際のキーボードが英国配列などの場合は、この表をそのまま当てはめず、現地の配列を確認してください。

## 「日本語が打てない」を切り分ける

USキーボードに半角／全角キーがなくても、日本語入力はできます。必要なのは、日本語の入力方式と、その入力方式で使える切り替え操作です。

Windowsでは、次の順に確認すると整理しやすくなります。

1. **入力方式があるか**：入力切り替え一覧に、日本語IMEまたは導入したKeyroIMEがあるか確認します。`Windows + Space` は、追加済みの入力方式を選ぶための操作です。
2. **日本語／英数字のモードはどちらか**：選んだIMEの表示やメニューで確認します。入力方式を選ぶ操作と、そのIME内で日本語を有効にする操作は別です。
3. **配列が合っているか**：半角の `@` や括弧を入力し、キーの割り当てを確かめます。
4. **そのアプリだけの問題か**：メモ帳でも試し、アプリ固有のキー操作やリモート接続先の設定と分けて確認します。

共用PCで日本語入力方式が用意されていない場合は、管理担当者に相談してください。KeyroIMEの導入も、そのPCの利用ルールに沿って行います。

## KeyroIMEで、USキーボードと日本語入力を組み合わせる

![海外勤務や留学での日本語入力と、JIS・ANSI切り替えを紹介するKeyroIMEの原図](https://raw.githubusercontent.com/keyro-jp/keyro-academy/main/media/keyro6-1.png)

Windows版KeyroIME Proは、JIS／ANSIの配列切り替えに対応しています。紹介画像の「KANA-SWITCHER」は、この切り替え機能を示しています。

- **配列を切り替える**：トレイメニューの配列設定、または **`Alt + ;`**。セミコロン位置のキーを使い、JIS／ANSIを切り替えます。
- **日本語／英数字を切り替える**：配列切り替えとは別の操作です。KeyroIMEの入力モードを確認します。Windows版の案内では **`Alt + ~`** がモード切り替えに使われます。ここでいう `~` は、USキーボードのEsc下・数字1の左にあるキーで、Shiftを追加する意味ではありません。

まずKeyroIMEを入力方式として選び、ANSI側の設定で `Shift + 2` が半角の `@` になるかを確認します。その後、日本語入力に切り替えて、かな・漢字変換を試してください。ショートカットが反応しない場合は、入力方式の選択とアプリ側の競合を確認し、メニュー操作でも切り分けます。

この設定はKeyroIMEの動作に関わるものです。すべてのソフトや他のIMEのキー設定を、一括で変更する機能ではありません。

## 予習は、短いメールと1行の式で

手元にUSキーボードがあれば、メモ帳で次の内容を入力してみましょう。見本を貼り付けるのではなく、自分で打って、迷うキーを確認します。

```text
To: dev@example.com
Subject: "Study plan" (2026)
total = (a + b)
留学先から資料を共有します。
```

1回目は記号の位置を確認し、2回目は英数字と日本語の切り替えを確認。最後に、普段使うブラウザーやエディターでも同じ文章を打ちます。「どのキーで止まったか」「何回打ち直したか」をメモしておくと、出発前に練習する箇所が絞れます。

キーボードの違いは、事前に知って小さく試せる準備の一つです。語学や仕事の内容に集中できるよう、自分の入力環境を整えておきましょう。

KeyroIMEの対応環境・利用条件・最新版は[公式リリース](https://github.com/keyro-jp/KeyroIME-Releases/releases)で確認できます。日本の職場でUS配列に慣れた人が困るケースは、[こちらの記事](https://github.com/keyro-jp/keyro-academy/blob/main/content/jis-ansi-tokyo-ja/article.md)で紹介しています。
