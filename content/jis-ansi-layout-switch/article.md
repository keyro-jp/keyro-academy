# JISとUSを行き来する人へ。Alt＋;で配列を切り替える

会社のPCはJIS、自宅はUS。海外の客先ではANSI、持ち歩くノートPCは日本語配列。環境が変わるたびに、`@`、括弧、コロンの位置を考えていませんか。

KeyroIME ProのWindows版には、JIS／ANSIの配列設定を切り替える機能があります。トレイメニューに加え、**`Alt + ;`** で切り替えられます。

## ANSIとUS、JISの違い

ANSIは主に物理キーの形と並び、USは文字の割り当てを指します。日常ではまとめてUS配列と呼ばれることもあります。JISは日本語キーボードで使われる配列です。

海外にもISO形状や各国固有の文字配列があります。渡航先や海外製PCが必ずUS配列とは限りません。まずキーボードの印字とOS設定を確認してください。

## よく使う記号を比較

一般的なUS英語配列と日本語JIS配列を、対応する設定で使う場合の例です。

| 文字 | US英語配列 | 日本語JIS配列 |
| --- | --- | --- |
| `@` | `Shift + 2` | Pの右の `@` キー |
| `"` | `Shift + '` | `Shift + 2` |
| `(` / `)` | `Shift + 9` / `Shift + 0` | `Shift + 8` / `Shift + 9` |
| `=` | `=` キー | `Shift + -` |
| `+` | `Shift + =` | `Shift + ;` |

## KeyroIME Proで切り替える

![JISとANSIをAltとセミコロンで切り替えるKeyroIMEの紹介画像](https://raw.githubusercontent.com/keyro-jp/keyro-academy/main/media/keyro6-1.png)

1. Windowsの入力方式でKeyroIMEを選びます。
2. 通知領域のKeyroIMEアイコンを開き、「キーボード配列設定」を確認します。
3. JISまたはANSIを選ぶか、`Alt + ;` を押します。ショートカットは物理的なセミコロン位置のキーを使います。
4. メモ帳で `@ " ( ) = +` を入力し、期待する結果か確認します。

切り替え後の状態はトレイ表示でも確認できます。ショートカットが反応しない場合は、アプリがキー操作を先に受け取っていないかを確認し、トレイメニューからも試してください。

## 変わるもの、変わらないもの

この機能が切り替えるのはKeyroIMEの文字配列処理です。次のものは物理的には変わりません。

- キーの形や大きさ
- キーに印刷された文字
- JISキーボードの変換・無変換キー
- 他のIMEやすべてのアプリのショートカット

また、JIS／ANSIの切り替えと、ひらがな／英語の入力モードは別の設定です。記号が合っていても日本語が入力できない場合は、入力モードを確認してください。

## 同じ短文で設定を決める

```text
To: dev@example.com
Subject: "Layout test" (2026)
total = (a + b)
```

JISとANSIの両方で入力し、記号の打ち直し回数と完成時間を記録します。複数のPCを使う人は、端末ごとに同じテストをすると、どの設定が指の記憶に合うか分かります。
