# 東京の職場で「@が打てない」？JIS・US配列の違いと切り替え方

新しい職場で、最初の英文メールを書こうとする。いつもの感覚で `Shift + 2` を押したら、出てきたのは `@` ではなく `"`。コードの括弧も、計算式の記号も、なぜか指の記憶と合わない。

US配列に慣れた人が日本語キーボードのPCに替えると、こんな戸惑いが起きます。タイピングの腕が落ちたわけではありません。まず確かめたいのは、**キーボードの形・Windowsの配列設定・IMEの入力モード**です。

この記事では、東京のオフィスで支給PCを使い始める場面を例に、違いの見分け方とKeyroIMEでの切り替えを紹介します。KeyroIME開発元からの機能紹介を含みます。

[中文](https://github.com/keyro-jp/keyro-academy/blob/main/content/jis-ansi-tokyo-zh/article.md) · [English](https://github.com/keyro-jp/keyro-academy/blob/main/content/jis-ansi-tokyo-en/article.md)

## 「配列」を3つに分けると、原因が見えてくる

1. **物理配列**：Enterやスペースの形、キーの数。日本語キーボードには変換・無変換などのキーがあります。
2. **論理配列**：押したキーをどの文字として扱うか。Windowsの日本語106/109と英語101/102などの設定が関わります。
3. **IMEの状態**：日本語・英数字、全角・半角、IME独自のキー処理。アプリ側のショートカットも影響します。

ANSIは物理的なキー配置を指す呼び方で、USは文字の割り当てを指します。日常会話ではまとめて「US配列」と呼びがちですが、厳密には別のものです。海外にもISOなどの物理配列や各国の文字配列があり、「海外のPCはすべてUS」ではありません。

## メールとコードで迷いやすい記号、早見表

以下は、一般的なUS英語配列と日本語JIS配列を、それぞれ対応する設定で使う場合の比較です。**半角英数字を入力できる状態**で確認してください。IMEやキー変更ツールが動作している場合は結果が変わることがあります。

| 入力したい文字 | US英語配列 | 日本語JIS配列 |
| --- | --- | --- |
| `@` | `Shift + 2` | Pの右の `@` キー |
| `"` | `Shift + '` | `Shift + 2` |
| `(` / `)` | `Shift + 9` / `Shift + 0` | `Shift + 8` / `Shift + 9` |
| `=` | `=` キー | `Shift + -` |
| `+` | `Shift + =` | `Shift + ;` |

日本語キーボードの変換・無変換キーは、日本語入力を操作するためのキーです。スペースやEnterの形も異なるため、記号の割り当てを切り替えても、物理的な押し心地まで同じになるわけではありません。

## まずはメモ帳で、切り分ける

メールの送信画面や本番のコードではなく、メモ帳で次の文字列を入力してみましょう。

```text
dev@example.com
"Tokyo" (2026)
total = (a + b)
```

- `Shift + 2` が `"` になる：日本語配列として処理されている可能性があります。キーの印字と期待する配列を確認します。
- 記号は合うが全角になる：配列に加え、IMEの全角・半角設定を確認します。
- メモ帳では合い、特定のアプリだけ違う：アプリのショートカットやリモート接続先の設定も確認します。

Windowsの入力言語とキーボード設定は、同じ意味ではありません。日本語を入力したいからといって、物理キーボードまで日本語配列でなければならないわけではありません。会社の管理PCでは、設定やソフトの導入方法を社内ルールに合わせてください。

## KeyroIMEで、JISとANSIを切り替える

![JISとANSIの切り替え、Altとセミコロンのショートカットを紹介するKeyroIMEのバナー](https://raw.githubusercontent.com/keyro-jp/keyro-academy/main/media/keyro6-1.png)

KeyroIME ProのWindows版には、**JIS／ANSIの配列切り替え**があります。上の紹介画像では「KANA-SWITCHER」と表記しています。

1. 対応するKeyroIME Proを導入し、入力方式としてKeyroIMEを選びます。
2. トレイメニューの配列設定、または **`Alt + ;`** でJIS／ANSIを切り替えます。ショートカットはセミコロン位置のキーを使います。
3. 入力先に戻り、半角の記号を入力する状態で `Shift + 2` と上の例文を確認します。ANSI側で `@` になるか、JIS側で期待する割り当てになるかを見ます。
4. メール、エディターなど、実際に使うアプリでも同じ確認をします。

この操作はKeyroIMEの配列設定を切り替えるものです。キーの印字や形、他のIMEの設定、すべてのアプリのショートカットを一括で変更するものではありません。切り替わらない場合は、KeyroIMEが選択されているか、アプリがキー操作を先に受け取っていないかを確認してください。

また、**配列の切り替えと、日本語／英数字の切り替えは別の操作**です。「@は打てるが日本語にならない」ときは、配列を再変更する前に入力モードを確認しましょう。

## 指の記憶に合う設定を、同じ文章で比べよう

設定を決めるときは、いつも書くメールや短いコードを、同じ条件で入力してみるのがおすすめです。「完成までの時間」「記号の打ち直し回数」「モードを切り替えた回数」を記録すると、自分の仕事に合うか判断しやすくなります。固定の高速化率を約束するものではありません。
